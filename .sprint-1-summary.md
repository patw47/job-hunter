## Décisions clés

### Résolution des alias lazy (au scoring, pas au chargement)

`resolve_alias` est une fonction pure distincte de `load_aliases`. Le dict est chargé une fois en début de session ; la résolution s'applique token par token dans le match rate engine (Sprint 2). Pas de dénormalisation dans `load_aliases`.

### Parsing Markdown minimaliste sans dépendance externe

`load_keywords` et `load_aliases` itèrent sur `text.splitlines()` — zéro dépendance à un parser Markdown. Suffisant pour le format contrôlé de SKILLS_MASTER.md. Si le format évolue vers du YAML front-matter ou des tableaux imbriqués, réviser.

### `DEFAULT_SKILLS_MASTER_PATH` via env var

Le chemin VPS `/home/thehunter/.openclaw/workspace/the-hunter/SKILLS_MASTER.md` est le défaut. Les tests et les environnements CI utilisent `SKILLS_MASTER_PATH` pour pointer vers un fichier local sans mocker `open`.

### 102 keywords, 21 alias

Le contenu actuel de SKILLS_MASTER.md produit 102 keywords distincts et 21 entrées d'alias. Ces chiffres évoluent au fil de la calibration (SKILLS_MASTER est un fichier vivant).

## Gotchas et contraintes découvertes

- **Parenthèses dans les bullets** : la ligne `- Playwright, Selenium (web automation)` produit le token `"Selenium (web automation)"`. Le matching via `in` sur le texte d'offre fonctionnera quand même si l'offre dit "Playwright" seul. Pas de parsing des parenthèses — hors scope Sprint 1.
- **Case-sensitive par conception** : `resolve_alias` est strict. Les variantes de casse (`"vector db"` vs `"Vector DB"`) doivent être gérées par le caller (Sprint 2 Match Rate Engine) via `.title()` ou lookup lowercase si nécessaire.
- **Table header `Terme offre`** : skipé explicitement dans `load_aliases`. Si le header change de libellé, la condition `term == "Terme offre"` doit être mise à jour — ou remplacée par une détection de position (première ligne non-séparateur après le heading).
- **`## Alias table` exact** : `load_aliases` cherche `stripped.startswith("## Alias table")`. Sous-sections ou variantes (`## Alias Table`, `## Alias`) ne seraient pas reconnues. Format contrôlé, risque faible.
- **Chemin de déploiement** : `skills_loader.py` doit être déployé dans `/opt/apps/job-hunter/` sur le VPS (cohérent avec `deduplication.py`, `linkedin_scraper.py`). La constante `DEFAULT_SKILLS_MASTER_PATH` pointe déjà vers le bon chemin VPS.
