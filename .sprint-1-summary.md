# Sprint 1 — Weekly Reporter — Résumé d'implémentation

## Ce qui a été implémenté

- **`weekly_stats.py`** — module CLI + library qui lit le sheet MATCHES via `matches_store.open_matches()`, filtre les lignes sur la semaine cible (lundi–dimanche ISO), et calcule :
  - `total_scanned`, `total_qualified` (≥60%), `notifications_sent`, `cvs_generated`, `letters_generated`, `applications_sent`, `responses_received`
  - `avg_match_rate`, `source_breakdown` (indeed/linkedin en %), `top_matches` (top 3 par match_rate, hors Envoyé/Ignoré)
  - Output JSON stdout compatible avec l'input format de `weekly-reporter` SKILL.md
  - CLI : `python weekly_stats.py [--week YYYY-MM-DD]` (lundi de la semaine cible)

- **`hunter_server.py`** — aucun changement nécessaire ; `/report` → `weekly-reporter` était déjà câblé dans `SKILL_MAP` (ligne 32).

- **`workflow-weekly-report.json`** — workflow n8n : Schedule Trigger (vendredi 18h, cron `0 18 * * 5`) → Execute `weekly_stats.py` → Parse JSON → POST `/report` → Check result → Send Telegram.

- **`tests/test_weekly_stats.py`** — 39 tests unitaires (285 total, zéro régression).

## Décisions clés

- `letters_generated` = `cvs_generated` : CV et lettres sont toujours générés ensemble selon la logique du tracker.
- `top_matches` exclut les statuts `_STATUSES_APPLIED` **et** `Ignoré` : représente les offres qualifiées non encore postulées.
- Lecture via `sheet.get_all_values()` (1 appel API unique) pour éviter le quota gspread.
- Mois n8n : cron `0 18 * * 5` = vendredi 18h UTC. Ajuster si le VPS est en timezone non-UTC.

## Gotchas et contraintes découvertes

- **`hunter_server.py`** avait déjà `/report` dans `SKILL_MAP` — pas touché.
- `parser.error()` appelle `sys.exit()` directement — le `return` suivant est unreachable, retiré.
- Le `datetime` mock dans `test_default_week_is_current_iso_week_monday` doit patcher `weekly_stats.datetime` et non `datetime.date` globalement pour ne pas casser `fromisoformat`.
- SKILL.md attend les `top_matches` avec `status` en string libre (pas nécessairement "applied") — la valeur du sheet est passée telle quelle.
- n8n workflow livré avec `"active": false` — à activer manuellement sur le VPS n8n.
