# Sprint 0 — Google Cloud & Google Sheets Tracker — Résumé d'implémentation

## Ce qui a été implémenté

- `test_sheets.py` : script de smoke test Python pour valider la connectivité Google Sheets
  - 7 phases : pre-flight credentials → auth gspread → ouverture spreadsheet → existence onglets → headers → write test row → read-back → cleanup
  - Crée les 3 onglets avec leurs headers si absents (`MATCHES`, `SCANNED_HASHES`, `PENDING_MATCHES`)
  - Headers définis par onglet (voir ci-dessous)
  - Exit code 0 = tout OK, 1 = au moins un échec
  - Retry sur HTTP 429 (quota), gestion explicite 403 (permissions insuffisantes)

## Headers définis

| Onglet | Colonnes |
|--------|----------|
| `MATCHES` | job_id, date_scanned, title, company, location, remote, url, source, match_rate, skills_found, status, cv_drive_link, letter_drive_link, applied_at |
| `SCANNED_HASHES` | sha256, date_scanned, url, title, company, source |
| `PENDING_MATCHES` | job_id, date_scanned, title, company, location, url, match_rate, skills_found, source, rank |

## Décisions clés

- **Shebang** : `#!/home/thehunter/venv/bin/python3` — même venv que le service systemd (commit `d7daa24` confirme que le venv system est requis pour google-auth).
- **gspread service_account()** — pas d'OAuth browser flow. Credentials path hardcodé à `/opt/apps/job-hunter/credentials.json`.
- **Spreadsheet name** : `"job-hunter-tracker"` (déduit du README). Si le spreadsheet a un nom différent, modifier la constante `SPREADSHEET_NAME`.
- **Création auto des onglets** : le script crée les onglets manquants plutôt que de juste échouer — pratique pour le setup initial.
- **Sentinel timestampé** : `__TEST_SMOKE___{timestamp}` pour éviter les collisions entre runs concurrents.

## Gotchas et contraintes découvertes

- **gspread 5.x requis** : utilise `google-auth` (pas `oauth2client` déprécié). Installer dans le venv thehunter : `sudo -u thehunter /home/thehunter/venv/bin/pip install gspread google-auth`
- **Permissions Editor obligatoires** : le service account doit avoir le rôle Editor (pas Viewer) sur le spreadsheet — erreur 403 explicitement rapportée.
- **`row_values()` tronque les cellules vides en fin de ligne** : la comparaison des headers est faite avec padding `(raw + [""] * len(expected))[:len(expected)]` pour une comparaison exacte.
- **`/opt/apps/job-hunter/` n'existe pas encore** : créer le dossier et y placer `credentials.json` + `test_sheets.py` avant de lancer. Le `.gitignore` exclut déjà `credentials.json`.
- **Déploiement** : copier `test_sheets.py` vers `/opt/apps/job-hunter/test_sheets.py` et lancer avec `sudo -u thehunter /home/thehunter/venv/bin/python3 /opt/apps/job-hunter/test_sheets.py`.
