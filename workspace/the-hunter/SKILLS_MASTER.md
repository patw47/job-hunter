# Skills Master — Match Rate Keywords

## Usage

Fichier utilisé par le Layer 2 du pipeline (Python, zero tokens) pour calculer le taux de match entre une offre et le profil de Patricia.

```
Match Rate = mots-clés trouvés dans l'offre / total mots-clés dans l'offre × 100
```

Seuil minimum : 60%. Notification immédiate : ≥ 80%.
